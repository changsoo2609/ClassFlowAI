ClassFlowAI 사용 안내
======================

ClassFlowAI는 화면을 캡처하여 OCR 또는 이미지 해석으로 처리하고,
수업별 캡처 흐름을 관리하는 프로그램입니다.

현재 기본 모델
- OCR: nvidia/nemotron-ocr-v2
- CAP 이미지 해석 및 OCR 수업 흐름 해석: google/diffusiongemma-26b-a4b-it

CAP 기본 모델은 이미지·문서·코드·UI 화면을 빠르게 해석하는 멀티모달 모델입니다.
API 요청은 Google Cloud가 아니라 NVIDIA NIM의 무료 개발용 endpoint로 전송됩니다.
무료 endpoint는 체험 크레딧과 호출 제한이 있으며 영구·무제한 무료 서비스는 아닙니다.


1. 처음 실행
------------

1) INSTALL_FIRST.bat을 실행합니다.
2) 설치가 끝나면 START_HERE.bat을 실행합니다.
3) 실행 준비 상태가 CMD 진행 바로 표시됩니다.
4) 설정에서 NVIDIA API 키를 입력합니다.

NVIDIA API 키는 NVIDIA Build에서 발급한 endpoint용 키를 사용합니다.
Google API 키나 Google Cloud 결제 설정은 필요하지 않습니다.


2. 기본 단축키
-------------

- Ctrl + Shift + S: 화면 캡처
- 휠클릭: OCR / CAP 전환
- Ctrl + 휠클릭: 감지 일시정지 / 다시 시작
- Shift + 휠클릭: ClassFlowAI 창 표시 / 최소화


3. OCR 모드
-----------

OCR 모드는 화면의 글자를 빠르게 추출해 즉시 보여 줍니다.
수업 흐름용 의미 해석은 별도 백그라운드 작업으로 진행됩니다.

화면 캡처
→ OCR 실행
→ 오른쪽 결과창 표시
→ OCR 텍스트 자동 복사

OCR이 부정확하면 [OCR 보정 후 복사]를 사용합니다.
원본 이미지와 OCR 결과를 비교해 수정한 뒤 자동 복사합니다.

빠른 OCR이 끝나면 원본 이미지와 OCR 결과를 함께 사용한 해석이 자동으로 시작됩니다.
해석 완료 전에도 OCR 텍스트를 바로 사용할 수 있으며, 완료된 해석은 수업 흐름에 반영됩니다.
백그라운드 수업 흐름 해석은 CAP와 같은 DiffusionGemma 기본 모델을 사용합니다.
[결과 수정]으로 완료된 수업 흐름 해석의 제목과 본문을 직접 고칠 수 있습니다.


4. CAP 모드
-----------

CAP 모드는 클립보드의 원본 이미지를 유지하면서
화면의 의미, 구조와 흐름을 해석합니다.

CAP 캡처 후에는 해석 텍스트를 자동 복사하지 않습니다.
따라서 Windows 캡처 도구가 클립보드에 넣은 원본 이미지가 유지됩니다.

화면 캡처
→ 원본 이미지 클립보드 유지
→ CAP 해석 결과를 오른쪽 결과창에 표시

해석 텍스트가 필요할 때만 [CAP 해석 복사]를 누릅니다.
[CAP 원본 이미지 복사]를 누르면 이전에 캡처한 CAP 원본 이미지를 클립보드에 다시 넣을 수 있습니다.
다시 복사한 이미지는 새 캡처로 중복 등록되지 않습니다.
[결과 수정]으로 CAP 해석의 오타나 표현을 직접 고칠 수 있습니다.
수정은 API를 다시 호출하지 않으며 모델 원본은 별도로 보존됩니다.
[원본으로 복원]을 선택하면 이미지, 캡처 ID, 촬영 시각과 순서를 바꾸지 않고 수정 내용만 제거합니다.

timeout, 연결 오류, HTTP 429·500·502·503·504만 5초 후 한 번 자동 재시도합니다.
HTTP 400·401·403·404·410은 자동 재시도하지 않습니다.
자동 재시도 뒤에도 실패하면 같은 캡처 기록과 원본 이미지를 재사용하는 [다시 시도] 동작을 제공합니다.
재시도 과정에서 캡처 ID, 이미지 파일과 기록을 중복 생성하지 않습니다.


5. 설정
------

[기본 / 모델]
- 캡처 저장 위치
- 단축키
- NVIDIA API 키
- OCR 모델 ID와 모델 페이지 URL
- CAP 추론 모델 ID와 모델 페이지 URL

기본 / 모델 탭은 별도 스크롤 없이 한 화면에 표시됩니다.
실제 API 요청에는 모델 ID가 사용됩니다.
모델 페이지 URL은 해당 모델 설명을 열기 위한 주소입니다.
현재 CAP 기본 모델 ID는 `google/diffusiongemma-26b-a4b-it`입니다.
기존 schema 9 설정에 종료된 Qwen 기본 모델이 저장되어 있으면 schema 10으로 올리면서 현재 기본 모델로 전환합니다.
사용자가 직접 지정한 다른 모델 ID는 임의로 덮어쓰지 않습니다.

[CAP 프롬프트]
- 이미지 한 장을 해석할 때 사용하는 프롬프트

6. 수업 관리
-----------

[새 수업 시작]
- 현재 수업의 기록과 원본 이미지를 그대로 보존합니다.
- 설정의 캡처 저장 위치 아래 `날짜\시간` 형식으로 새 수업 폴더를 만듭니다.
- 새 수업은 캡처, 기록, 출력과 로그를 이전 수업과 분리해 저장합니다.

[이전 수업 열기]
- 저장 위치에서 열 수업 폴더를 선택합니다. 이전 버전의 `lessons\lesson_날짜_시간` 폴더도 그대로 열 수 있습니다.
- 기존 버전에서 사용하던 저장 폴더도 captures 또는 state 폴더가 있으면 열 수 있습니다.
- 마지막으로 연 수업은 다음 실행 때 다시 열립니다.

OCR 또는 CAP 처리가 진행 중이면 처리가 끝난 뒤 수업을 전환해야 합니다.

[캡처 순서 조정]
- 현재 수업 캡처 목록에서 선택한 항목을 위 또는 아래로 이동할 수 있습니다.
- 원래 촬영 순서 복원은 확인창에서 승인한 경우에만 실행합니다.
- 순서를 바꿔도 원본 파일명, 촬영 시각, 캡처 ID와 OCR/CAP 결과는 변경하지 않습니다.
- 변경된 순서는 `display_order`에 별도로 저장되며 수업을 다시 열어도 유지됩니다.

[수업 초기화]
- 예를 선택하면 현재 수업의 기록과 원본 이미지를 함께 삭제합니다. 삭제한 이미지는 복구할 수 없습니다.
- 아니요를 선택하면 기록만 초기화하고 원본 이미지는 유지합니다.
- 취소를 선택하면 아무것도 변경하지 않습니다.
- 삭제하지 못한 이미지가 있으면 해당 파일을 유지하고 경로를 안내합니다.

OCR 또는 CAP 처리가 진행 중이면 처리가 끝난 뒤 수업을 초기화해야 합니다.


7. 미니 상태창
-------------

- 파랑: OCR 대기
- 갈색: CAP 대기
- 주황: 진행 중
- 초록: 완료
- 빨강: 실패
- 회색: 일시정지

왼쪽 버튼으로 끌어서 이동할 수 있습니다.
더블클릭하면 메인 창을 표시합니다.
오른쪽 버튼을 누르면 메인 창 열기, 감지 일시정지·재개와 프로그램 종료 메뉴가 표시됩니다.
프로그램 종료는 확인창에서 확인한 경우에만 실행되며 저장된 수업 기록과 이미지는 유지됩니다.
Shift + 휠클릭은 메인 창이 앞에 있으면 최소화하고, 아니면 앞으로 표시합니다.


8. 주요 버튼
-----------

[새 수업 시작]
현재 수업을 보존하고 독립된 새 수업 폴더로 전환합니다.

[이전 수업 열기]
저장된 수업 폴더를 선택해 캡처와 처리 결과를 다시 불러옵니다.

[수업 초기화]
현재 수업 기록을 초기화하며 원본 이미지의 삭제 또는 유지를 선택합니다.

[수업 흐름]
OCR과 CAP 결과를 같은 수업 흐름으로 확인합니다.
캡처 그림과 해설·코드·메모를 실제 순서대로 각각 구분해 표시합니다.
그림을 우클릭하면 원본 이미지를, 텍스트나 코드를 우클릭하면 해당 내용만 복사합니다.
전체 문서 복사 없이 그림과 텍스트 블록을 각각 복사합니다.

[OCR 보정 후 복사]
OCR 결과를 이미지와 비교해 수정하고 자동 복사합니다.

[수업 흐름 해석 다시 실행]
OCR 추출 후 자동으로 진행되는 백그라운드 해석을 필요할 때 다시 실행합니다.
이 작업은 현재 OCR 표시나 클립보드 내용을 바꾸지 않습니다.

[CAP 해석 복사]
CAP 해석 텍스트를 사용자가 필요할 때 클립보드에 복사합니다.
수정한 해석이 있으면 수정본을 복사합니다.

[결과 수정]
완료된 CAP 해석 또는 OCR 수업 흐름 해석을 직접 수정합니다.
수정본은 결과 표시와 수업 흐름에 우선 사용되며 모델 원본으로 언제든 복원할 수 있습니다.

[CAP 원본 이미지 복사]
현재 선택한 CAP 캡처의 원본 이미지를 클립보드에 다시 복사합니다.

[캡처 폴더 열기]
원본 캡처 이미지가 저장된 폴더를 엽니다.

[설정]
API 키, 저장 위치, 단축키, 모델과 프롬프트를 관리합니다.


9. 설정과 로그 저장 위치
-----------------------

사용자 설정과 API 키는 프로그램 소스 폴더가 아닌 다음 위치에 저장됩니다.

- 설정: `%LOCALAPPDATA%\ClassFlowAI\settings.json`
- API 키: `%LOCALAPPDATA%\ClassFlowAI\secrets.json`
- 모델 요청 진단: `%LOCALAPPDATA%\ClassFlowAI\model_request_diagnostics.jsonl`

진단 로그에는 endpoint, 모델 ID, payload 구조, 이미지 MIME과 바이트 크기,
HTTP 오류 코드·메시지와 request ID만 기록합니다.
API 키, Authorization 값, 프롬프트 전문, base64 이미지와 전체 응답 본문은 기록하지 않습니다.


10. 현재 모델과 NVIDIA 무료 API 안내
------------------------------------

기존 기본 모델 `qwen/qwen3.5-397b-a17b`는 NVIDIA에서
2026-07-27 00:00 UTC에 EOL 처리되어 HTTP 410을 반환합니다.
현재 기본 모델 `google/diffusiongemma-26b-a4b-it`는 같은 NVIDIA chat completions
endpoint와 기존 이미지 payload 구조로 실제 HTTP 200 연결을 확인했습니다.

NVIDIA 모델 페이지:
https://build.nvidia.com/google/diffusiongemma-26b-a4b-it

무료 API 주의사항
- NVIDIA 개발·시험용 Free Endpoint와 사용자별 체험 크레딧을 사용합니다.
- 사용량과 동시 트래픽에 따라 rate limit 또는 throttling이 발생할 수 있습니다.
- 무료 제공 조건과 모델 제공 여부는 NVIDIA 정책에 따라 변경될 수 있습니다.
- 운영·상용 사용은 NVIDIA 또는 서비스 제공자의 별도 구독과 이용 조건을 확인해야 합니다.


11. 현재 검증 상태와 제한
------------------------

- Windows 실행 경로와 사용자 설정 경로 확인
- DiffusionGemma 비민감 테스트 이미지 실제 호출: HTTP 200 확인
- 전체 Python unittest 134개 통과
- 전체 Python 컴파일과 app.py import 통과
- API 키, 사용자 설정, 캡처 이미지, 기록 JSON과 로그는 Git에서 제외

실제 응답 시간과 해석 품질은 이미지 크기, 화면 내용, NVIDIA 서버 상태와 네트워크에 따라 달라집니다.
중요한 수업에서는 OCR/CAP 결과를 확인하고, NVIDIA 무료 크레딧과 endpoint 제공 상태를 함께 점검하세요.
